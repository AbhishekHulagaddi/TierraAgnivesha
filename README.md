# 🌿 Tierra Agnivesha

### AIAPGET – Ayurveda Entrance Coaching Platform

**Tierra Agnivesha** is an AIAPGET (All India AYUSH Post Graduate Entrance Test) coaching platform focused on helping **Ayurveda students** prepare for postgraduate entrance examinations.

🌐 **Website:** https://tierraagnivesha.com/

---

## 🎯 About Tierra Agnivesha

Tierra Agnivesha aims to provide Ayurveda students with accessible and structured resources for **AIAPGET preparation**.

The platform is intended to support aspirants through:

* 📚 AIAPGET preparation resources
* 📝 Practice questions and MCQs
* 📖 Study and revision materials
* 🎯 Exam-oriented preparation
* 🧠 Concept-based learning
* 🚀 Future online coaching and learning features

---
